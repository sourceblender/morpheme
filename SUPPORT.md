# Support

## Where to ask

| Question type               | Where to go                                                                  |
| --------------------------- | ---------------------------------------------------------------------------- |
| Bug report                  | [GitHub Issues](https://github.com/sourceblender/morpheme/issues/new?template=bug_report.md) |
| Feature request             | [GitHub Issues](https://github.com/sourceblender/morpheme/issues/new?template=feature_request.md) |
| Security issue              | [SECURITY.md](./SECURITY.md) — email `security@sourceblender.dev`            |
| Code of conduct violation   | [CODE_OF_CONDUCT.md](./CODE_OF_CONDUCT.md) — email `conduct@sourceblender.dev` |
| Usage or design question    | [GitHub Issues](https://github.com/sourceblender/morpheme/issues/new) — start the title with `[question]` |

Issues cover every channel: the Rust crates, the CLI, the Python package
and the WASM bindings. Please say which one you use and its version
(`morpheme --version`, `morpheme.__version__`, or the crate version).

## Response expectations

This is an early-stage project with no SLA. Please be patient, and please
search existing issues before opening a new one.

## Commercial support

Not offered at this time.
