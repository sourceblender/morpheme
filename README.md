# Benchmark results

Written by the `Benchmark tracking` workflow; do not edit by hand.

- `results/<host>/<utc timestamp>-<sha>.json`: one `scripts/benchmark_baseline.py`
  report per run.
- `results/<host>/latest.json`: copy of the newest report for that host; the next
  run compares against it.

See docs/benchmarks.md on the main branch, "Dedicated host tracking".
